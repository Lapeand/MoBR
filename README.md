# NutriAI — Android + API

Рабочий MVP дневника питания для ВКР. Kotlin / Compose-клиент подключён к FastAPI вместо статичных данных. Исходная зелёная Material 3 стилистика сохранена; прежние макеты остаются в Preview Gallery.

## Что реализовано

- Регистрация, вход, JWT access + одноразовые refresh-токены с ротацией, выход.
- Трёхшаговый профиль: цель, пол, возраст, рост, вес, активность; редактирование и серверная норма по Mifflin–St Jeor.
- Чат: текст, системный голосовой ввод Android, фото из галереи / приложения камеры, превью вложения.
- Агент возвращает **предложение**, а не молча записывает еду. Проверка каждого продукта, изменение порции с пересчётом КБЖУ, подтверждение или отмена.
- Ручной ввод с КБЖУ на порцию, поиск продукта по введённому штрихкоду в Open Food Facts.
- Дневник с выбором даты, удаление записей, график 7 дней, сумма КБЖУ и доли БЖУ по энергии.
- Рекомендации из двух прозрачных рецептов с масштабированием по остатку калорий и макросов; добавление через то же подтверждение.
- CSV за 7 дней, лимит 20 сообщений Free в сутки (UTC), серверный demo-переключатель Premium только для разработки.
- Зашифрованные Android Keystore сессия и снимок последнего дневника для чтения без сети. Выход очищает их.
- PostgreSQL + MinIO в Docker Compose, Alembic, Swagger, CI сборка APK и тесты.

## Быстрый локальный запуск

Нужны Python **3.11+** (локально проверено на **3.12**), JDK **17**, Android SDK **35**. Docker использует Python 3.11.

```sh
cd backend
python3.12 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export JWT_SECRET="$(python -c 'import secrets; print(secrets.token_hex(32))')"
alembic upgrade head
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

В локальном режиме SQLite и папка `uploads/` создаются автоматически. Для постоянных сессий сохраните JWT_SECRET в окружении: без него dev-сервер генерирует новый ключ при каждом запуске. Документация: `http://localhost:8000/docs`; проверка: `http://localhost:8000/health`.

В другом терминале:

```sh
cd android
./gradlew assembleDebug
```

Откройте `android/` в Android Studio, выберите **Gradle JDK 17** и запустите приложение на эмуляторе. По умолчанию сервер — `http://10.0.2.2:8000/`. Это адрес компьютера из Android-эмулятора, **не** адрес для физического телефона.

На телефоне через USB:

```sh
adb reverse tcp:8000 tcp:8000
./gradlew assembleDebug -PAPI_BASE_URL=http://127.0.0.1:8000/
```

Для VPS:

```sh
./gradlew assembleRelease -PAPI_BASE_URL=https://api.example.org/
```

Адрес также можно изменить на приветственном экране кнопкой **«Адрес сервера»**, без пересборки APK. Для телефона укажите HTTPS-адрес своего VPS или используйте USB reverse. Смена адреса очищает сессию и данные предыдущего сервера. URL обязательно заканчивается `/`. Ключ ИИ никогда не помещается в APK. HTTP разрешён только debug-сборке; release требует HTTPS и настройки подписи владельцем приложения.

## ИИ и фото

На backend задайте `OPENAI_API_KEY` и, при необходимости, `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`). Например, перед запуском сервера экспортируйте переменные в окружение или используйте `uvicorn ... --env-file ../.env`.

С ключом сервер использует [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=chat) со строгой JSON-схемой и дополнительной Pydantic-валидацией ответа для текста и фото. КБЖУ точно совпавших с локальным справочником продуктов заменяются справочными; прочие помечаются как `ai-estimate`. Никакие параметры профиля в запрос модели не передаются. Фото нормализуются в JPEG, EXIF удаляется; максимум загрузки 8 МБ.

**Без ключа:** текст работает по небольшому встроенному справочнику (борщ, хлеб, курица, гречка, овсянка, банан и др.). Пример: `борщ 300 г, хлеб 40 г`. Если граммы не указаны — приблизительно 200 г (яйцо 60 г); всё проверяется пользователем. Неизвестные продукты вызывают уточнение. Распознавание фото честно отвечает, что нужен ключ, а не создаёт фиктивную еду. Ручной дневник доступен всегда при работающем API.

Голос использует установленную службу Android через системное окно распознавания; она может обращаться в сеть. Whisper fallback пока не реализован.

## Docker / VPS

```sh
cp .env.example .env
# Замените JWT_SECRET, пароли PostgreSQL и MinIO, при необходимости добавьте ключ ИИ.
docker compose up --build -d
```

API привязан к `127.0.0.1:8000`, базы и MinIO не публикуются наружу. Контейнер API перед запуском выполняет `alembic upgrade head`. Настройте DNS и HTTPS reverse proxy на сервере. Пример Caddy:

```caddy
api.example.org {
    request_body {
        max_size 10MB
    }
    reverse_proxy 127.0.0.1:8000
}
```

Резервируйте Docker volumes `postgres_data` и `media_data`. Настройте сетевые лимиты запросов, мониторинг и политику хранения перед публичным запуском. VPS, домен, ключ провайдера, боевой HTTPS и подпись release не включены в репозиторий и требуют реальных реквизитов окружения.

## Проверки

```sh
cd backend
python -m pytest -q
DATABASE_URL=sqlite:///migration-check.db alembic upgrade head
DATABASE_URL=sqlite:///migration-check.db alembic check

cd ../android
./gradlew testDebugUnitTest lintDebug assembleDebug
# Запустите dev API и эмулятор; тест создаёт отдельного пользователя:
adb shell pm clear com.nutriai.mvp
./gradlew connectedDebugAndroidTest
```

Smoke-проверка Android: регистрация → профиль → текст «борщ 300 г, хлеб 40 г» → подтверждение → 247 ккал в аналитике → пересоздание Activity с сохранённой сессией.

## Архитектура и границы MVP

`runtime/NutriApp.kt` — подключённые экраны; `NutriViewModel` — состояние и события; `Repository` — Retrofit, refresh, защищённый кэш. `ui/` содержит общие компоненты, тему и исходные дизайн-превью. Для небольшого MVP зависимости создаются вручную в AndroidViewModel, кэш — зашифрованный снимок без Room; Hilt, CameraX и Vico не добавлены. Фото снимает системное приложение камеры, графики рисует Compose Canvas. Нет офлайн-очереди записи: без сети доступен только последний сохранённый снимок, ошибочные отправки не считаются успешными.

Рекомендации детерминированы, не генерируются LLM. Premium демонстрирует снятие лимита; оплата отсутствует. Для переключения запустите **dev** API с `ENABLE_DEMO_PLAN=true`, используйте кнопку в настройках debug APK. В production endpoint недоступен даже с этим флагом. В MVP рекомендации и CSV открыты обоим тарифам.

Уведомления по расписанию, Whisper fallback, оценка точности на размеченном наборе, сканирование штрихкода камерой, удаление аккаунта через UI, production rate limiting и Play Billing остаются отдельными этапами. Это не реализованные возможности.

КБЖУ и порции — оценки, зависят от рецепта. Приложение предназначено для дневника взрослых (18+), не для медицинских назначений. Значения встроенного справочника ориентировочные. Данные Open Food Facts: [источник и лицензия ODbL](https://world.openfoodfacts.org/data); происхождение сохраняется у продукта.

Исторический план интерфейса: [`docs/PLAN.md`](docs/PLAN.md). Текущее описание реализации — этот README.
