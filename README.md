# NutriAI — Android с ИИ без собственного сервера

**Установите APK: дневник хранится на телефоне, ИИ вызывается напрямую через интернет.**

Версия **2.1.0-ai**, Android 8.0+ (API 26). Kotlin, Jetpack Compose, Material 3, SQLite. Бэкенд, VPS, Docker, регистрация и адрес сервера не требуются.

## Установка и показ

1. Установите `NutriAI-AI.apk`, включите интернет. В предоставленной владельцу демосборке ключ уже настроен.
2. Заполните цель, параметры тела и активность. Приложение рассчитает суточную норму.
3. Напишите: `На обед съел тарелку борща 300 граммов и хлеб 40 граммов.`
4. ИИ разберёт описание. Приложение возьмёт данные из справочника и рассчитает **247 ккал**. Проверьте порции, сохраните запись.
5. Спросите: `Сколько калорий осталось на сегодня?` ИИ получает фактический суточный баланс. Обычный ответ не создаёт запись в дневнике.
6. Попробуйте блюдо вне справочника. ИИ даст приблизительный состав, а приложение пересчитает его на указанную массу. Источник «Оценка ИИ» виден перед сохранением.
7. Откройте аналитику, профиль и рекомендации. Экспортируйте CSV из настроек.
8. В настройках выключите «ИИ через интернет» и добавьте `банан 100 г`: получится **89 ккал** без сети.

APK обновляет предыдущую локальную debug-сборку с тем же ключом подписи. Для APK из GitHub Actions подпись может отличаться. Если Android не разрешает обновление, сначала сохраните CSV, затем удалите старую версию и установите новую: удаление приложения стирает дневник.

## Как работает ИИ

- Модель: `nvidia/nemotron-3-super-120b-a12b:free`, OpenRouter.
- Один HTTPS-запрос прямо с Android на `https://openrouter.ai/api/v1/chat/completions`.
- Ответ ограничен JSON Schema: текст, продукты, массы и значения на 100 г. Приложение проверяет формат, размер ответа, диапазоны и количество продуктов.
- Для известных продуктов значения ИИ игнорируются: используется встроенный справочник из **51 продукта и блюда**. Для новых блюд — явно отмеченная приблизительная оценка ИИ.
- Умножение на массу, суммирование КБЖУ, суточная норма и пересчёт изменённой порции выполняются в Kotlin на телефоне.
- ИИ не имеет права самостоятельно сохранять или удалять записи. Каждое предложение проходит подтверждение пользователя.
- При таймауте, отсутствии сети, отклонённом ключе или лимите бесплатной модели приложение показывает причину и использует локальный разбор текста. Справочник, ручной ввод и дневник доступны всегда. Автоматических повторных платных запросов и перехода на другую модель нет.
- Ключ можно заменить в настройках. Введённый ключ шифруется через Android Keystore, не отображается и не логируется.

Поддержка JSON Schema проверяется у выбранного провайдера (`require_parameters=true`). Протокол: [Structured Outputs OpenRouter](https://openrouter.ai/docs/guides/features/structured-outputs).

## Данные и ограничения

SQLite хранит профиль, дневник по датам, историю чата и черновик. Фото лежат во внутренней папке приложения. Записи сохраняются после перезапуска, подтверждение одного request_id не создаёт дубль. Доступны дневные суммы, график недели, баланс БЖУ, удаление записи, экспорт последних 7 дней в CSV и сброс с подтверждением.

В режиме ИИ отправляются текст текущего запроса, последние 6 сообщений выбранного дня и рассчитанные суточные суммы/цели КБЖУ. Имя, возраст, рост, вес и пол из профиля не отправляются. Дневник не синхронизируется и целиком не загружается. Фото не отправляются в OpenRouter: выбранная интеграция текстовая, автоматического распознавания еды по фото нет. Не вводите в чат данные, которые не хотите передавать провайдеру. Обработка запросов зависит от правил OpenRouter/NVIDIA; бесплатный endpoint может сохранять запросы.

Фото из камеры/галереи нормализуются в JPEG без EXIF, видны в чате и записях. Для расчёта подпишите название еды и массу.

Голос — Android on-device SpeechRecognizer на Android 12+ с установленным локальным русским языковым пакетом. При отсутствии поддержки используйте текст. После распознавания текст обрабатывается выбранным режимом помощника.

Без ИИ локальный разбор поддерживает русские названия, г/кг/мл, десятичную запятую и штуки. Неизвестные блюда требуют ручного ввода. Рекомендации в профиле локальные: 4 рецепта с масштабированием по остатку калорий и всех БЖУ. Свободные предложения ИИ в чате являются приблизительными советами, а не гарантированным планом питания.

КБЖУ и порции приблизительные; всегда проверяйте состав. Это учебный дневник для взрослых, не медицинское назначение. Backup Android отключён; перед удалением приложения сохраните CSV.

## Сборка

Откройте `android/` в Android Studio: **JDK 17**, SDK **35**, minSdk 26.

Для сборки со своим ключом создайте **неотслеживаемый** `android/openrouter.properties`:

```properties
apiKey=YOUR_OPENROUTER_KEY
```

Либо задайте переменную окружения `OPENROUTER_API_KEY`. Не коммитьте ключ. Ключ сборки находится внутри APK и извлекаем: такой APK предназначен для личного учебного показа. Для распространения собирайте без ключа и вводите индивидуальный ключ в настройках.

```sh
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. В CI нет личного ключа; собранный артефакт `NutriAI-Android-APK` требует ввода ключа в настройках. Режим без сети работает сразу.

Проверка локальных сценариев:

```sh
adb shell svc wifi disable
adb shell svc data disable
adb shell cmd connectivity airplane-mode enable
cd android
./gradlew connectedDebugAndroidTest
```

Проверка реального ИИ отдельно, с интернетом и настроенным ключом (два запроса):

```sh
cd android
./gradlew connectedDebugAndroidTest \
  -Pandroid.testInstrumentationRunnerArguments.class=com.nutriai.mvp.DiaryFlowTest#liveAiParsesNaturalLanguageThenAndroidCalculatesAndStores \
  -Pandroid.testInstrumentationRunnerArguments.liveOpenRouter=true
```

Обычные тесты и CI не вызывают живую модель; тест ИИ включается только явным параметром.

## Код

- `runtime/NutriApp.kt`, `NutriViewModel.kt` — экраны, состояние, локальные действия и выбранный режим помощника.
- `OpenRouterAgent.kt` — HTTPS, JSON Schema, ограниченный контекст, проверка ответа, калькуляция результата.
- `AiSettings.kt` — режим и зашифрованный пользовательский ключ.
- `Repository.kt` — SQLite, транзакции, черновик, однократный перенос прежнего снимка.
- `Nutrition.kt` — справочник, локальный разбор, КБЖУ, нормы, рекомендации и CSV.
- `OfflineSpeech.kt`, `LocalPhoto.kt` — голос и локальные изображения.
- `docs/QA.md` — проверки; `docs/PLAN.md` — исторический план серверной архитектуры.

Серверный код удалён из актуальной версии и остался только в истории Git.
