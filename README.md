# NutriAI — полностью локальное Android-приложение

**Установите APK и пользуйтесь на телефоне. Сервер, аккаунт, ключ ИИ, Docker и интернет не нужны.**

Версия **2.0.0-local**, Android 8.0+ (API 26). Kotlin, Jetpack Compose, Material 3, SQLite. У APK **нет разрешения INTERNET**; Retrofit, HTTP-клиент и удалённый загрузчик картинок удалены.

## Установка и показ преподавателю

1. Установите `NutriAI-offline.apk` на Android. Разрешите установку APK из выбранного файлового менеджера, если Android попросит.
2. Укажите цель, параметры тела и активность. Регистрации нет.
3. Во вкладке «Агент» введите `борщ 300 г, хлеб 40 г`.
4. Проверьте порции и нажмите «Сохранить в дневник». В аналитике будет **247 ккал**.
5. Отключите Wi-Fi и мобильную сеть / включите авиарежим. Добавьте ещё еду, закройте и снова откройте приложение: записи останутся.
6. Откройте профиль, рекомендации, добавьте предложенное блюдо через подтверждение. Из настроек сохраните CSV.

Новый APK обновляет прежнюю локальную debug-сборку с тем же ключом подписи. Если старый APK был скачан из GitHub Actions и Android сообщает о несовместимой подписи, сначала экспортируйте нужные данные, затем удалите старое приложение и установите новое. Данные удалённого приложения не сохраняются.

## Функции без сети

- Профиль: имя, цель, пол, возраст, рост, вес, активность; локальная норма по Mifflin–St Jeor.
- Текстовый помощник по встроенному справочнику из **51 продукта и блюда**. Русские названия, граммы/килограммы/миллилитры, десятичная запятая, количество штук. Например: `рис 0,15 кг, курица 150 г`; `яйцо 2 шт`.
- Если масса не указана, используется стандартная порция, видимая перед сохранением. Неизвестное или неоднозначное блюдо требует уточнения. Это локальный алгоритм и справочник, **не облачная LLM**.
- Поиск по справочнику (кнопка книги), ручное добавление блюда (кнопка +).
- Подтверждение каждого продукта, изменение порции с пересчётом КБЖУ, отмена. Черновик сохраняется между запусками. Повторное подтверждение не создаёт дубль.
- SQLite: профиль, дневник за любые дни, история чата по датам. Не «кэш», а основное постоянное хранилище.
- Дневная сумма КБЖУ, график 7 дней, баланс БЖУ по энергии, удаление записей.
- Четыре варианта рекомендаций с масштабированием по оставшимся калориям и макронутриентам. Реальные рецепты из справочника, без случайной подстановки данных.
- Экспорт последних 7 дней в UTF-8 CSV через системное сохранение файла.
- Фото из камеры/галереи сохраняются в закрытой папке приложения, нормализуются в JPEG без EXIF, видны в чате и у записи. При отправке фото **укажите название и массу текстом**: расчёт делается по тексту. **Автоматического распознавания блюда по фото нет**. Фото без подписи сохраняется в чате и предлагает указать еду; фиктивная запись не создаётся.
- Голос — только Android `createOnDeviceSpeechRecognizer`, Android 12+ и установленный локальный русский языковой пакет. Облачного fallback и автоматического скачивания модели нет. Если устройство не поддерживает локальное распознавание, остаются текст и справочник. Наличие микрофона и нужного языкового пакета проверяйте на конкретном телефоне; остальные функции от них не зависят.
- Сброс всех данных только после подтверждения в настройках. Нет тарифов, лимита сообщений и оплаты.

## Хранение и обновление

SQLite и фото находятся во внутренней приватной папке приложения. Данные не уходят в сеть и не синхронизируются. Android backup отключён. Удаление приложения / очистка данных удаляет дневник; CSV храните отдельно.

При обновлении прежней серверной версии приложение может однократно перенести профиль и записи последнего сохранённого снимка, если он доступен и расшифровывается. Полный серверный дневник автоматически не загружается. Новая версия не использует старые токены и адреса API.

КБЖУ во встроенном справочнике ориентировочные для готовой еды. Состав и способ приготовления влияют на результат. Свой продукт добавляйте вручную, вводя значения **на всю порцию**. Приложение предназначено для учебного дневника взрослых (18+), не для медицинских назначений.

## Разработка

Откройте `android/` в Android Studio. Нужны **JDK 17**, Android SDK **35**; minSdk 26.

```sh
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Debug APK подписан автоматически и подходит для показа на телефоне. Для публикации в магазине потребуется собственная release-подпись.

Полная проверка на эмуляторе без интернета:

```sh
adb shell svc wifi disable
adb shell svc data disable
adb shell cmd connectivity airplane-mode enable
cd android
./gradlew connectedDebugAndroidTest
```

Gradle скачивает зависимости при сборке на компьютере; установленному APK сеть не нужна. В CI выполняются unit-тесты, lint, сборка APK и отдельные UI-тесты на эмуляторе с отключённой сетью. Артефакт APK называется `NutriAI-offline-APK`.

## Структура

- `runtime/NutriApp.kt` — рабочие Compose-экраны.
- `NutriViewModel.kt` — состояние, локальные действия, импорт фото.
- `Repository.kt` — SQLite, транзакции, сохранение черновика, однократный перенос старого снимка.
- `Nutrition.kt` — справочник, разбор текста, расчёт нормы и КБЖУ, рекомендации, CSV.
- `OfflineSpeech.kt`, `LocalPhoto.kt` — локальные голос и изображения.
- `ui/` — общие компоненты и исторические дизайн-превью. Прежние макеты auth доступны только в Preview Gallery; в работающем приложении их нет.
- `docs/QA.md` — проверки. `docs/PLAN.md` — историческое ТЗ прежней архитектуры; текущая версия определяется этим README.

Серверный код и Docker-конфигурация удалены из актуальной версии; их история осталась в Git.
